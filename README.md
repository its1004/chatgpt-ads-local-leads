# 챗GPT 광고, 우리 동네 고객만 잡기 (지역 타겟팅 + 문의 전환 추적)

> **English summary** — A field-tested setup log for running ChatGPT ads (OpenAI Ads Manager, beta) for a local service business in Korea on a small budget. It covers three things the onboarding flow does not make obvious: (1) region-level targeting inside Korea only shows up when you search the location box **in English** (e.g. `Busan`), (2) optimizing for contact-form leads needs a data source, a `lead_created` conversion event, the pixel in `<head>`, and one `oaiq("measure", ...)` call on form success, (3) a monthly cap below the daily minimum is done with a **campaign-total budget plus an end date**, which can only be set after publishing. Snippets are in `snippets/`. Verified on 2026-11-19; the product is in beta and screens may change.

서비스 가능 지역이 정해져 있는 지역 업체가 챗GPT 광고(OpenAI 광고 관리자, 베타)를 처음 세팅하면서 실제로 막혔던 지점과 해결 방법을 정리했습니다.
광고 관리자 온보딩이 추천해 주는 캠페인을 그대로 게시하면 **전국 노출 · 클릭 목표 · 일일 예산**으로 나갑니다. 이 글은 그걸 **서비스 지역만 · 문의 전환 목표 · 월 예산 상한**으로 바꾼 기록입니다.

- 확인 일자: 2026-11-19 (광고 관리자 베타, 원화 계정)
- 적용 환경: AI 빌더로 만든 지역 서비스 업체 홈페이지 (문의 폼이 있는 사이트)

## 한눈에 보기

| 항목 | 온보딩 추천값 | 바꾼 값 |
|---|---|---|
| 위치 | 대한민국 | 서비스 가능한 시·도만 |
| 목표 | 클릭 | 전환 (문의 제출) |
| 예산 | 일일 예산 | 캠페인 총예산 + 종료일 30일 뒤 |
| 도착 URL | 홈페이지 메인 | 문의 페이지 |
| 광고 문구 | 지역 언급 없음 | 헤드라인 맨 앞에 지역명 |

## 1. 지역 타겟팅: 시·도는 영어로 검색해야 나온다

캠페인 편집 창의 "이 캠페인의 위치" 검색창에서 직접 확인한 결과입니다.

| 검색어 | 결과 |
|---|---|
| 한글 시·도 이름 (예: `부산광역시`) | 0건 |
| 한글 지명 일부 (예: `부산`) | 우편번호 단위만 |
| 영어 시·도 이름 (예: `Busan`) | 유형이 **지역**인 시·도 항목 |
| `Korea` | 시·도 목록 (Seoul, Busan, Daegu, …) |

설정 순서:

1. 기본으로 들어가 있는 `대한민국` 칩을 X로 제거합니다. 남겨두면 전국에 노출됩니다.
2. 시·도 이름을 영어로 검색해 유형이 "지역"인 항목을 추가합니다.
3. 저장 후 요약 카드의 위치가 바뀌었는지 확인합니다.

더 좁히려면 한글 구·읍면 이름으로 검색해 우편번호 단위로 넣을 수 있습니다.

## 2. 광고 문구: 입력 한도보다 미리 보기 기준으로 줄인다

입력 한도는 헤드라인 32자, 설명 54자입니다. 하지만 모바일 미리 보기에서는 그보다 훨씬 먼저 잘립니다.

| 요소 | 잘린 길이 | 잘리지 않은 길이 |
|---|---|---|
| 헤드라인 | 18자 (13자쯤에서 잘림) | 12자 |
| 설명 | 44자 (둘째 줄에서 잘림) | 22자 |
| 브랜드 이름 | 11자 (8자쯤에서 잘림) | 더 짧게 |

- 지역명을 헤드라인 맨 앞에 두면, 문구가 잘리더라도 지역은 보입니다. 서비스 지역 밖 사람이 눌러서 나가는 클릭비를 줄이는 용도입니다.
- "크리에이티브 개선"이 켜져 있으면 AI가 제목과 설명을 바꿔서 내보낼 수 있습니다. 저장 후 문구가 내가 넣은 것과 같은지 다시 확인하세요.
- 광고에 뜨는 이름은 **브랜드 이름**입니다. 설정 > 일반에서 "이 이름을 브랜드 이름과 법적 사업자명으로 사용합니다" 체크를 풀면 계정 이름 / 사업자 등록명 / 브랜드 이름을 따로 넣을 수 있습니다.
- 브랜드 로고는 필수입니다. 없으면 "광고 게재를 시작하려면 계정 로고를 업로드하세요" 경고가 뜹니다. PNG 또는 JPG, 정사각형을 권장합니다.

## 3. 문의를 전환으로 잡기

클릭 목표는 클릭까지만 최적화합니다. 문의 기준으로 돌리려면 광고 관리자 > 전환 메뉴의 4단계를 모두 끝내야 합니다.

```
① 데이터 소스(픽셀) 만들기        ← 광고 관리자
② 전환 이벤트 만들기 (리드 생성)   ← 광고 관리자
③ 홈페이지에 픽셀 + 이벤트 호출    ← 내 사이트 코드
④ 캠페인 목표를 전환으로, 이벤트 연결 ← 광고 관리자
```

### ①② 광고 관리자에서

- 전환 > 데이터 소스 만들기. "만들기"를 누르면 전환 약관에 동의하게 됩니다.
- 전환 이벤트 만들기: 기준 이벤트 **리드 생성**(`lead_created`), 이름은 "문의 제출"처럼 알아볼 수 있게.
- 기여 기간 기본값은 클릭 후 30일 / 조회 후 1일입니다.

### ③ 홈페이지에서

| 파일 | 넣는 곳 |
|---|---|
| [`snippets/pixel-base.html`](snippets/pixel-base.html) | 모든 페이지 공통 `<head>`, 한 번만 |
| [`snippets/lead-event.js`](snippets/lead-event.js) | 문의 폼 전송이 **성공한 직후** |

AI 빌더로 만든 사이트라면 광고 관리자의 설정 코드를 붙여 넣고 이렇게 요청하면 됩니다. 경로는 내 사이트에 맞게 바꾸세요.

```
위 코드는 OpenAI(ChatGPT) 광고 픽셀 설정 코드입니다. 아래 작업을 해주세요.
(1) 이 스크립트를 수정 없이 그대로 사이트 모든 페이지의 공통 head 최상단 가까이에 한 번만 삽입.
(2) 문의 폼이 서버로 전송되어 성공 응답을 받은 직후에만 브라우저에서
    if (window.oaiq) { oaiq("measure", "lead_created", { type: "customer_action" }); } 를 1회 호출
    (전송 실패 시에는 호출하지 않음).
(3) 기존 기능(문의 저장, 알림, 관리자 페이지, 화면 디자인과 문구)은 일절 변경하지 말 것.
(4) 운영 DB 데이터는 보존.
(5) 빌드 확인 후 커밋하고 운영 사이트에 재배포. 완료 후 변경한 파일과 삽입 위치를 요약해 주세요.
```

### ④ 캠페인에 연결할 때 주의

- 목표를 "전환"으로 바꾸면 청구 방식 기본값이 **노출수(CPM)** 로 잡힙니다. 화면 설명으로는 CPM이 조회 후 전환까지 포함해 최적화하고, 클릭수(CPC)는 전환 수가 제한됩니다. 어느 쪽이든 "편집"에서 고를 수 있으니 모르고 넘어가지만 않으면 됩니다.
- 전환 이벤트가 하나도 없는 상태에서 목표만 전환으로 바꾸면 "사용 가능한 전환 이벤트가 없습니다"가 뜹니다. ①②를 먼저 하세요.

### 확인 방법

1. 사이트를 열어 `<head>`에 픽셀이 있고 `typeof window.oaiq`가 `"function"`인지 봅니다.
2. 광고 관리자 > 전환 > 이벤트 스트림 > **폴링 시작**.
3. 데이터 소스 필터가 **내 픽셀**인지 확인합니다. 픽셀이 여러 개면 기본 필터가 다른 픽셀로 잡혀 있어 0건으로 보입니다.
4. 테스트 문의를 1건 넣습니다. `lead_created` / `pixel_sdk` 행이 수 초 안에 나타나면 끝입니다.
5. 테스트가 끝나면 픽셀 코드의 `debug: true`를 지웁니다.

## 4. 월 예산 상한: 일일 예산이 아니라 총예산 + 종료일

월 예산이 "일일 최소액 × 30일"보다 작으면 일일 예산으로는 맞출 수 없습니다.

| 방식 | 월 상한을 맞출 수 있나 |
|---|---|
| 일일 예산 | 원화 계정 일일 최소액이 ₩25,000이라 그보다 작게 설정 불가. 일일 예산은 평균값이라 하루 최대 2배, 7일 최대 7배까지 나갈 수 있음 |
| 캠페인 총예산 | 총액이 고정됨. 한 달에 쓸 금액을 그대로 입력 |

- **종료일을 꼭 넣습니다.** 온보딩 화면에는 종료일 칸이 없고, 게시한 뒤 캠페인 목록 > ⋯ > 캠페인 수정 > "종료일 설정"에서 넣습니다. 종료일이 없는 총예산 캠페인은 60일에 걸쳐 나눠 쓰도록 잡힌다고 합니다.
- 총예산에서 일일 예산으로 한 번 바꾸면 다시 총예산으로 돌아갈 수 없다고 합니다.
- 일일 예산 화면의 "일일 최대 지출액 2배 / 7일 최대 7배" 문구는 광고 관리자 화면에서 직접 확인했습니다. 일일 최소액, 60일 페이싱, 되돌리기 제한은 아래 참고 자료의 서술이고 제가 직접 검증한 것은 아닙니다.

## 알아둘 점

- **실제 계약은 잡히지 않습니다.** 픽셀이 보는 건 홈페이지 문의까지입니다. 전화·현장에서 이뤄지는 계약은 문의 건별로 따로 기록해 문의당 비용과 계약당 비용을 각각 계산해야 합니다.
- **사업체 인증**: 게시 후 "광고를 계속 게재하려면 사업체 인증을 완료하세요" 배너가 뜹니다. 인증 전에도 게재는 시작되지만 나중에 중단될 수 있다고 안내합니다. 비즈니스 유형은 사업자등록번호(EIN/TIN) 입력이 필수입니다.
- **광고 검토**: 게시 직후 상태는 "게재 안 함 · 광고 검토 중"이고, 이번에는 몇 분 뒤 "게재 중"으로 바뀌었습니다.
- **진단 경고**: 픽셀만 쓰면 전환 > 진단에 "최근 서버 간 이벤트가 없습니다"(중간) 경고가 남습니다. 서버에서 Conversions API로도 보내라는 뜻이고, 픽셀만으로도 측정은 됩니다.
- **고급 매칭**: 문의자의 연락처를 해시해 넘기면 매칭이 좋아지지만, 고객 개인정보를 광고 플랫폼에 보내는 일입니다. 사이트의 개인정보 안내 문구와 맞는지 먼저 확인하세요.
- **소액 예산의 기대치**: OpenAI가 권장하는 시작 클릭 입찰가가 3~5달러라고 알려져 있어, 소액 예산으로 받는 클릭 수는 많지 않습니다. 첫 달은 문의당 비용을 재는 테스트로 보는 게 맞습니다.
- **베타입니다.** 화면 구성과 정책은 바뀔 수 있습니다.
